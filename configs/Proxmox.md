# Hardware componenets for VM Environment


# Operating Systems for installation

# Initial set up
*Install Proxmox V9.2.10

# Remote connection
* Install Tailscale on computer
* Start the Tailscale program on your computer
* Connect to the IP Address of the Proxmox server via Tailscale (100.81.36.41:8006)

# Install EVE-NG

* Download EVE-NG VM and upload it to Proxmox
* Create a new VM in proxmox (EVE-NG ISO, 80GB Storage, 8GB RAM, Network vmbr0, model VirtIO)
* Run EVE-NG and install
* Connect to EVE-NG via browser using IP Address (192.168.1.186)
